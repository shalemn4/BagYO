# BagYo – Luggage Logistics Platform (Frontend MVP)

BagYo is a modern, minimalist web application built to streamline luggage logistics and on-the-go storage solutions. This repository houses the complete early-stage frontend architecture, focusing on a highly responsive user experience, type-safe state management, and optimized asset delivery.

> **Project Status:** This project served as the core frontend MVP for BagYo during its operations (Nov 2025 – Jan 2026). The repository is currently maintained as a technical showcase of production-ready Vue 3 and TypeScript architecture.

---

## 🛠️ Tech Stack & Architecture

The application is engineered with a focus on performance, type safety, and clean geometric UI design:

*   **Framework:** [Vue 3](https://vuejs.org/) (Composition API)
*   **Language:** [TypeScript](https://www.typescriptlang.org/) (Strictly typed interfaces and component props)
*   **Styling:** [Tailwind CSS](https://tailwindcss.com/) (Utility-first CSS, custom fluid layouts, and soft-shadow configurations)
*   **Build Tool:** [Vite](https://vitejs.dev/) (Lightning-fast HMR and optimized production bundling)

---

## ✨ Key Features & Technical Highlights

*   **Type-Safe Frontend Architecture:** Leveraged TypeScript to enforce strict typing across reactive state, API payloads, and component props, reducing runtime errors.
*   **Minimalist UI & Responsiveness:** Implemented a clean, geometric design system using Tailwind CSS, ensuring pixel-perfect layouts and flawless responsiveness across mobile, tablet, and desktop viewing modes.
*   **State & Workflow Optimization:** Utilized Vue's reactivity system to build high-performance UI workflows, interactive booking flows, and state-driven dashboards.
*   **Asset Performance:** Integrated custom 2D line-art animations and lightweight vectorized branding assets optimized for rapid page load times and high Core Web Vitals scores.
